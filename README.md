☕ Desafios Java — Aula 02 Alura.

Este projeto foi criado para praticar os fundamentos da linguagem Java, desenvolvendo pequenos programas e aplicando conceitos básicos de programação.

🎯 Objetivo

Praticar lógica de programação, declaração de variáveis, operações matemáticas, conversão de tipos e exibição de resultados no console.

📚 Desafios desenvolvidos

1. 🧮 Valor total de um produto

Declaração de variáveis double e int.

Multiplicação do preço pela quantidade.

Exibição do valor total da compra.

2. 💵 Conversão de dólar para real

Declaração da variável valorEmDolares.

Utilização da cotação de R$ 4,94 por dólar.

Conversão do valor para reais e impressão formatada.

3. 🏷️ Cálculo de desconto

Declaração do preço original e do percentual de desconto.

Cálculo do desconto em reais.

Exibição do preço final com desconto.

🛠️ Tecnologias utilizadas

Java — linguagem de programação.

Eclipse IDE — ambiente de desenvolvimento.

Git — controle de versão.

GitHub — hospedagem do código-fonte.

▶️ Como executar

Clone ou baixe este repositório.

Abra o Eclipse IDE.

Importe o projeto Java para o workspace.

Abra a classe ClasseDoDesafioMain.

Execute com Run As → Java Application.

🚀 Aprendizados

Durante esses exercícios, estou praticando:

Declaração e utilização de variáveis.

Tipos primitivos: int, double e char.

Manipulação de textos com String.

Operações matemáticas.

Casting de tipos.

Cálculo de porcentagem.
